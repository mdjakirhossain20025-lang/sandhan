সন্ধান — Supabase Email Subscription Setup

১) Supabase Dashboard → SQL Editor এ নিচের SQL চালান:

create table public.subscribers (
  id bigint generated by default as identity primary key,
  email text unique not null,
  created_at timestamptz not null default now()
);

alter table public.subscribers enable row level security;

create policy "Allow public newsletter signup"
on public.subscribers
for insert
to anon
with check (
  email ~* '^[A-Z0-9._%+-]+@[A-Z0-9.-]+\.[A-Z]{2,}$'
);

২) Supabase Project Settings → API থেকে Project URL এবং Publishable/Anon Key নিন।

৩) New Text Document.html ফাইলে:
   const SUPABASE_URL = "YOUR_SUPABASE_URL";
   const SUPABASE_ANON_KEY = "YOUR_SUPABASE_ANON_KEY";
   এখানে নিজের তথ্য বসান।

৪) Service Role / Secret Key কখনো HTML বা JavaScript-এ বসাবেন না।

৫) site-logo.png, favicon-48.png এবং apple-touch-icon.png একই ফোল্ডারে রাখুন।
